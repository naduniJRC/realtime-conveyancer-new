JRC SOFTWARE — PRESENTATION EDITION

OPEN THE WEBSITE
1. Extract this ZIP completely. Do not open index.html from inside the ZIP.
2. Open the extracted JRC_New_Website folder in VS Code.
3. Right-click index.html and choose Open with Live Server if that extension
   is installed. You can also open index.html directly in your browser.
4. Refresh the browser. If it shows the previous design, use Ctrl+Shift+R.

No npm install, build command, framework or internet connection is required.
GSAP and ScrollTrigger are included locally.
